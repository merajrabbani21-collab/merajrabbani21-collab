# Hi, I'm Meraj Rabbani

I build [Paperlane](https://paperlane.meraj.uno/), a free-to-start website for learning to code by typing.

## What Paperlane is

Most beginners watch tutorials and still freeze in front of an empty editor. Paperlane works the other way round. It shows you a small piece of code, explains it in plain words, and has you type it yourself. The code runs, and you see the output right away.

## What you can learn

- Python, JavaScript, TypeScript, SQL, Java, C++, C#, Rust, HTML/CSS and AI skills
- 36 levels per course, from a first line of code up to real projects
- Lessons assume no prior knowledge and teach one small piece at a time
- New ideas come back in later lessons, so they stick instead of being drilled once and forgotten
- XP, streaks and a daily goal to help you keep a habit

## Why it exists

Typing code builds familiarity with syntax and tools faster than reading about it. I wanted a place where a complete beginner can start in minutes, on a phone or a laptop, with no setup and no pile of tools to install.
